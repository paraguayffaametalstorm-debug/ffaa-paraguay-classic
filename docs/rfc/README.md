# 📄 RFC — Request for Comments

> **Propuestas formales de cambios grandes en el sistema.**
> **Última actualización:** 2026-09-17

## ¿Qué es un RFC?

Un RFC es un documento que describe una **propuesta formal** para un cambio significativo en el sistema. Sirve para:
- Documentar el problema.
- Proponer soluciones.
- Analizar alternativas.
- Registrar la decisión tomada.

## Nomenclatura

- **RFC-XXX** → ID único secuencial.

## Estados

| Estado | Significado |
|---|---|
| 📝 Draft | Borrador, en discusión |
| 🔄 Review | En revisión por stakeholders |
| ✅ Accepted | Aprobado, listo para implementar |
| ❌ Rejected | Rechazado, no se implementará |
| ⏸️ On Hold | Pausado, esperando algo |
